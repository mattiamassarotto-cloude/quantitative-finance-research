# Markowitz Portfolio Optimization

This project implements Modern Portfolio Theory (MPT) in Python using the Markowitz mean-variance optimization framework.

## Main Features

- Downloads historical market data using yfinance
- Computes logarithmic returns and correlation matrices
- Simulates thousands of random portfolios using Monte Carlo methods
- Optimizes portfolios for maximum Sharpe ratio and minimum variance
- Visualizes the efficient set of feasible portfolios

## Implementations

### Basic Model
- Portfolio optimization using a selected set of U.S. stocks.

### Extended Model
- Portfolio optimization using approximately 100 U.S. stocks.
- Monte Carlo simulation with large-scale portfolio generation.
- Robust optimization using multiple starting points.

## Technologies

Python, Pandas, NumPy, SciPy, Matplotlib, yfinance

## Example

The models analyse portfolio diversification and risk-return trade-offs using historical U.S. equity data.
