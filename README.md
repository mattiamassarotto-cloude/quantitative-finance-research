# Quantitative Finance Research

This repository contains Python implementations of quantitative finance models developed as part of my bachelor's thesis and independent research.

## Models Included

- GARCH(1,1) Volatility Modeling
- Dynamic Conditional Correlation (DCC-GARCH)
- Markowitz Portfolio Optimization
- Capital Asset Pricing Model (CAPM)
- Statistical Analysis of Financial Returns

## Technologies

- Python
- NumPy
- Pandas
- Statsmodels
- ARCH
- Matplotlib
- yfinance

## Objectives

The objective of this project is to investigate the behaviour of financial markets under different volatility regimes and evaluate the limitations of classical financial models during periods of market stress.
